# Аватар в Телемосте: настройка студии

Студия — компьютер с Windows, через который аватар выходит в Телемост участником «ИИ-помощник». Руководитель и команда заходят в Телемост со своих устройств, как обычно.

Схема: окно аватара (Chrome) → OBS → виртуальная камера Телемоста. Звук встречи → «микрофон» аватара. Голос аватара → микрофон Телемоста.

## Что поставить один раз

1. **OBS Studio** (obsproject.com). Виртуальная камера встроена.
2. **VB-CABLE A+B** (vb-audio.com, раздел VB-CABLE). Это два виртуальных провода для звука: один в каждую сторону. После установки перезагрузить компьютер.
3. **Яндекс Телемост** — приложение для Windows. Аватар открывается в **Chrome**, а Телемост — в приложении. Так Windows разводит звук двух программ по разным проводам. Две вкладки одного браузера развести нельзя.

## Звук

| Куда | Настройка |
|---|---|
| Звук встречи → аватару | Телемост → Настройки → Динамики: **CABLE-A Input**. В Chrome при запросе микрофона для окна аватара выбрать **CABLE-A Output** |
| Голос аватара → во встречу | Windows → Параметры → Система → Звук → Микшер громкости → Chrome → Вывод: **CABLE-B Input**. Телемост → Микрофон: **CABLE-B Output** |
| Слышать встречу самому | Панель звука → Запись → CABLE-A Output → Свойства → Прослушать → «Прослушивать с данного устройства» → свои наушники |

## Видео

1. Студия: `https://194-87-110-81.sslip.io/studio` в Chrome. Один раз **разрешить всплывающие окна** для этого адреса (значок справа в адресной строке).
2. За минуту до встречи студия сама откроет окно аватара 640×400. В окне выбрать **Russian** и нажать **Chat now**. Автозапуска в окне LiveAvatar нет.
3. OBS → Источники → «+» → **Захват окна** → окно аватара (Chrome). Растянуть на всю сцену, обрезать поля (Alt + перетаскивание края).
4. OBS → **Запустить виртуальную камеру**.
5. Телемост → Камера: **OBS Virtual Camera**. Имя участника: «ИИ-помощник Ивана Петрова».

Видео аватара можно свернуть в «картинку в картинке» кнопкой медиа в панели Chrome. Окно остаётся поверх остальных, а OBS продолжает его захватывать.

## Демонстрация экрана

- **Экран аватара.** Студия → кнопка «Экран аватара». Открывается страница 16:9 с повесткой, вопросами по прошлому протоколу, вопросами из истории и задачами участников. Обновляется сама раз в 30 секунд. В Телемосте: «Демонстрация экрана» → это окно.
- **Экран руководителя.** Руководитель показывает свой экран в Телемосте как обычно. Аватар экран не видит, LiveAvatar получает только звук. Поэтому то, что важно для протокола, лучше проговорить вслух.

## После встречи

Окно аватара закрывается само. Через минуту-две протокол из расшифровки уходит руководителю в Telegram на утверждение. Если аватара не включили, придёт одна строка: «прошла без аватара».

## Какие встречи

По умолчанию аватар ходит на **операционные** встречи рабочего дня. Список меняется строкой `AVATAR_CATEGORIES` в `.env` стенда, например `операционная,один_на_один`. Рабочий день задаёт `DEMO_DATE`, время — часы стенда.

## Проверка перед питчем (10 минут)

1. Тестовая встреча в Телемосте: студия плюс телефон.
2. На телефоне видно аватара, слышен его голос. Аватар отвечает на вопрос с телефона.
3. Демонстрация «экрана аватара» видна на телефоне.
4. Через 2 минуты после конца в Telegram пришёл протокол.

## Ссылка на встречу

- **Сейчас (вручную).** В окне «Новая встреча» и на странице встречи есть кнопка «Открыть Телемост». В новой вкладке нажмите «Создать видеовстречу», скопируйте ссылку в поле. Она уйдёт в приглашения, по ней же в начале встречи зайдёт робот с аватаром.
- **Автоматически.** Официальный API Телемоста работает только для Яндекс 360 для бизнеса (аккаунт на домене организации). Выпустите OAuth-токен с правом `telemost-api:conferences.create` и впишите в `.env` стенда строку `TELEMOST_OAUTH_TOKEN=<токен>`, затем перезапустите службу. Кнопка станет «Создать ссылку Телемоста», ссылка будет создаваться сама. Код — `pomoshnik/telemost.py`. На хакатоне автоматический режим живьём не проверен: у нас личный аккаунт Яндекса.
