# TASK_09: Аватар включается сам, студия, экран аватара, Телемост

**Исполнитель:** Claude. **Пункты ТЗ:** стр. 3, п. 3–5 («участвует во встрече как живой аватар — на одной платформе»). **Решения Пита 26.11:** площадка — Телемост; аватар включается сам по календарю; нужно маленькое окно и демонстрация экрана.

## Ожидаемое поведение

### Автопилот (`pomoshnik/studio.py`, без модели)
- Встречи рабочего дня (`DEMO_DATE` или сегодня) категорий из `AVATAR_CATEGORIES` (по умолчанию «операционная»). Время сравнивается по часам стенда на рабочий день.
- За `AVATAR_LEAD_MIN` (1) минуту до начала: контекст аватара (история, вопросы ревизора, прошлый протокол, задачи участников) и окно LiveAvatar на длительность встречи + 10 минут. Запись `avatar_auto_ready` в журнал. Руководителю в Telegram: встреча, ссылка на студию и экран аватара.
- Каждая встреча готовится один раз (журнал переживает перезапуск).
- После конца встречи: если сессия LiveAvatar завершена — расшифровка → черновик протокола с привязкой к встрече → Telegram (как кнопка «Встреча окончена»). Запись `avatar_auto_done`.
- Через 20 минут после конца без сессии — «встреча без аватара», руководителю одна строка, больше не ждём.
- Ошибка LiveAvatar не роняет стенд: запись в журнал и повтор на следующем шаге.

### Студия (`/studio`)
- Страница для компьютера, через который аватар выходит в Телемост. Опрашивает `GET /api/studio` раз в 10 с.
- Когда встреча готова и время пришло — сама открывает аватара **компактным окном** (640×400, его захватывает OBS). После конца встречи — закрывает окно.
- Подсказки: разрешить всплывающие окна один раз; в окне аватара нажать «Chat now»; видео можно свернуть в «картинку в картинке» кнопкой браузера.

### Экран аватара (`/avatar/screen?uid=`)
- 16:9 в облике «Голубое стекло»: встреча, участники, вопросы по прошлому протоколу, вопросы из истории, задачи участников. Обновляется сам. Студия показывает его в Телемосте демонстрацией экрана.

### Инструкция `ТЕЛЕМОСТ.md`
OBS: захват окна аватара → виртуальная камера. Звук: VB-Cable — звук Телемоста идёт в «микрофон» аватара, голос аватара — в микрофон Телемоста. Демонстрация экрана: студия показывает «экран аватара», руководитель — свой экран.

## Проверочные случаи
1. 09:58 при встрече в 10:00 — ничего; 09:59 — готово один раз, в Telegram ссылка; повторный шаг — без повторов.
2. Встреча не той категории — аватар не готовится.
3. После конца и завершённой сессии — черновик протокола с `meeting_uid`, `avatar_auto_done`; повторный шаг — без второго протокола.
4. Нет сессии через 20 минут — «без аватара», протокола нет.
5. Ошибка LiveAvatar — запись в журнал, стенд работает, на следующем шаге повтор.
6. `/api/studio`: ничего / готово (адрес окна, начало, конец) / закончилась.
7. Экран аватара показывает вопросы и задачи встречи; неизвестная встреча — 404.
