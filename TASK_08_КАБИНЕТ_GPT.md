## Разделы

Навигация: пять пунктов, на телефоне — нижняя панель или верхнее меню, без горизонтальной прокрутки. У каждого раздела элемент с `data-section="<ключ>"`.

| Ключ | Название | Пункт ТЗ | Что на экране |
|---|---|---|---|
| `today` | Сегодня | 1 | Карточки метрик; «Ждут только вас» — решения с кнопками «Согласовать», «Отказать», «Позже»; риски; встречи дня; просроченные и ближайшие задачи; окна для фокуса |
| `mail` | Переписка | 2 | Вкладки групп: **Контрагенты**, **Отделы** (подгруппы «Участники совещаний» и «Другие»), **Рассылки**, **Спам**, отдельная вкладка **Шаблоны**. Переключатель **Входящие / Исходящие** с числами. Внутри группы — список собеседников (`party`) с числом писем, по нажатию — письма собеседника по времени, по нажатию на письмо — текст, категория, что сделал помощник и почему |
| `meetings` | Совещания | 3–5 | **Большой календарь** (см. ниже). Справа или под ним карточка выбранной встречи. Ниже вкладки «Протоколы» и «Задачи». Форма «Расшифровка → протокол» |
| `memory` | Память и обучение | 6 | Поиск «что известно по…»; темы: последний статус, по нажатию — история с цитатами и источниками; правки руководителя (протоколы и шаблоны) |
| `profile` | Профиль и метрики | масштаб | Имя, цели, «только с подтверждением», правила по категориям, стиль, время плана; все метрики; журнал действий помощника |

### Шаблоны писем
Список шаблонов → редактор: тема, текст, список переменных вида `{имя}` (показать подсказкой). Кнопка «Сохранить» (`PUT`). Под редактором — **чат «Обсудить с помощником»**: руководитель пишет, например, «сделай теплее и короче», помощник отвечает и предлагает новый вариант (`POST …/discuss`). Предложение подставляется в редактор, но сохраняется только по кнопке «Сохранить». Ошибку 422 (неизвестная переменная) показать рядом с полем.

### Большой календарь
- Вид «Неделя»: колонки Пн–Пт (можно Сб–Вс, если есть встречи), шкала 08:00–20:00, встречи — блоки по времени и длительности, цвет по `category`. Пересекающиеся встречи — рядом, не друг на друге.
- Переключение недель «‹ ›» и кнопка «Сегодня» (день из `GET /api/today` → `day`, это учебная дата).
- Защищённые окна (`focus`) — заштрихованный фон.
- На ширине до 600 px — вид «День» (список встреч дня с переключением дней).
- Клик по встрече → карточка: время, участники, категория, протокол (статус, кнопки «Утвердить», «Править», «Отклонить» для черновика), вопросы по прошлому протоколу, вопросы из истории, задачи участников, кнопка «Аватар на встречу» → `/avatar?title=<название>`.

## Интерфейс (стык): API

Все ответы JSON, время — ISO 8601 с часовым поясом (`2026-12-08T14:10:00+05:00`), дата — `YYYY-MM-DD`. Примеры каждого ответа лежат в `tests/fixtures/cabinet/<имя>.json` — **верстайте по ним**. Все тексты из API выводятся только через `textContent` / `createElement` — в письмах чужой текст.

| Метод и адрес | Ответ (пример) | Что делает |
|---|---|---|
| `GET /api/today` | `today.json` | План дня |
| `POST /api/decisions/{event_id}` тело `{"verdict": "yes"\|"no"\|"later"}` | `{"ok": true}` | Решение по письму |
| `GET /api/mail` | `mail.json` | Все письма: `letters[]` и `groups[]` |
| `GET /api/templates` | `templates.json` | Шаблоны писем |
| `PUT /api/templates/{key}` тело `{"subject", "body"}` | один шаблон, как в списке; 422 `{"detail": "..."}` | Сохранить |
| `POST /api/templates/{key}/discuss` тело `{"message", "subject", "body"}` | `template_discuss.json` | Обсудить, не сохраняет |
| `GET /api/meetings?start=YYYY-MM-DD&days=7` | `meetings.json` | Встречи и защищённые окна за период |
| `GET /api/meetings/{uid}` | `meeting.json` | Карточка встречи |
| `GET /api/protocols` | `protocols.json` | Протоколы |
| `POST /api/protocols/{id}/approve` \| `/reject` | `{"ok": true}` | Утвердить и разослать / отклонить |
| `POST /api/protocols/{id}/edit` тело `{"instruction"}` | один протокол, как в списке | Правка руководителя |
| `POST /api/meetings/transcript` тело `{"title", "transcript", "minutes_ago"}` | `{"protocol_id": 3}` | Расшифровка → черновик протокола |
| `GET /api/tasks` | `tasks.json` | Задачи и сроки |
| `GET /api/memory?q=` | `memory.json` | Память, `q` — необязательный поиск |
| `GET /api/edits` | `edits.json` | Правки руководителя |
| `GET /api/profile` | `profile.json` | Профиль |
| `GET /api/metrics` | `metrics.json` | Метрики (`cards` — готовые подписи) |
| `GET /api/journal?limit=50` | `journal.json` | Последние действия |

Поля письма (`mail.json → letters[]`): `id`, `direction` (`in`/`out`), `at`, `from_name`, `from_email`, `to_name`, `to_email`, `subject`, `body`, `category`, `action`, `reason`, `group` (`counterparty`, `team`, `internal`, `newsletter`, `spam`), `party`, `party_note`. Группа `team` — «Отделы: участники совещаний», `internal` — «Отделы: другие». Подписи групп берите из `groups[]`.
