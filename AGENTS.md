# Codex — «ИИ-помощник руководителя»

Начинай с [README](README.md) и [плана подготовки](ПОДГОТОВКА.md). Сверяй объём работы с выбранным сценарием и официальным ТЗ, когда оно появится. При разработке записывай в TASK ожидаемое поведение, запуск и критерии проверки.

- Пит принимает продуктовые решения. Codex ведёт код, проверки и документацию. В отчёте указывай, как открыть результат и что удалось проверить.
- Этот репозиторий должен запускаться из собственного клона. В рабочей папке хакатона рядом есть учебное ядро клининга и тренировочные задачи. Их можно изучать локально. Порядок переноса заготовок уточняется у организаторов.
- Для демо держи учебный набор данных с вымышленными именами. Ключи используй через локальный `.env`. Рабочую переписку, токены и выгрузки с персональными данными храни вне истории Git.
- Когда согласуем сценарий, фиксируй правила доступа и допустимые действия в проверяемых условиях. В журнале сохраняй основания, решения человека и сведения о выполненных действиях.
