# TASK_16: Голос в Telegram

**Кто решил:** Пит, 27.11: «В ТГ нужно голосовое общение». Выбор Пита: распознавание — Whisper на нашем сервере (голос не уходит со стенда, ключи не нужны); ответы — текстом; голосом руководитель: отвечает на карточку решения, спрашивает «что по …», поручает и напоминает, правит протокол.

## Поведение

1. Руководитель шлёт голосовое → бот скачивает его, Whisper на сервере распознаёт (модель `small`, CPU, int8) → первой строкой «🎙 «что понял»».
2. Модель разбирает просьбу в одно из действий (JSON), **код проверяет и выполняет**:
   - **решение по текущей карточке** (`active_groups()[0]`): согласовать / отказать / позже; если руководитель сказал, что написать, — ответ по его словам. Ответ уходит наружу, а голос можно расслышать не так, поэтому — одна кнопка «Отправить» / «Не то» с текстом ответа. «Позже» — сразу.
   - **«что по …»** — ответ из памяти (`recall`).
   - **поручить / напомнить** человеку из оргструктуры — письмо ему от имени помощника; срок словами разбирает код (`parse_deadline`). Нет такого человека — так и сказать.
   - **назначить встречу** — в календарь и приглашения участникам (`create_meeting`); дату и время проверяет код.
   - **поправить протокол** — последний черновик на утверждении (`apply_edit`) и снова на утверждение.
   - **план** — график и сроки.
   - не понял — подсказка, что можно сказать.
3. Тот же разбор работает и для обычного текста, который не команда.
4. Распознавание идёт вне общего замка стенда: кабинет не ждёт, пока Whisper работает.

## Стык

- `pomoshnik/voice.py`: `LocalWhisper(model="small")` — вызывается как `transcribe(audio: bytes) -> str`.
- `pomoshnik/intents.py`: `parse(llm, text, context) -> dict` — разбор просьбы.
- `TelegramPult.download(file_id) -> bytes`.
- `Assistant.transcribe` — распознаватель (стенд ставит `LocalWhisper`, тесты — заглушку); `Assistant.act(text)`.
