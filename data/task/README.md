# Синтетический набор данных — трек «Цифровой аватар»

Все данные вымышленные: компания, люди, клиенты и суммы придуманы для хакатона. Реальная почта руководителя не передаётся.

| Файл | Что внутри |
|---|---|
| `inbox.csv` | 80 писем за неделю 7–11 декабря 2026. Поле `expected_action` — эталон, что агент должен сделать: `спросить_руководителя`, `делегировать`, `авто`, `в_сводку`, `игнорировать`; в `reason` — почему. По нему можно посчитать точность разбора почты. |
| `calendar.ics` | Календарь руководителя на 2 недели (7–18 декабря), около 25 встреч в неделю, у каждой категория: операционная, руководство, клиент, партнёр, деньги, один на один. |
| `org_structure.csv` | Руководитель, 7 подчинённых, руководитель руководителя и 3 коллеги — кому делегировать и чьи письма требуют подтверждения. |
| `tasks.csv` | Текущие задачи команды со сроками и статусами, в том числе просроченные. |
| `leader_profile.md` | Профиль руководителя: цели, правила решений, каналы, стиль. Шаблон того, что настраивается без программирования для любого руководителя. |

Плюс в папке задачи: примеры протоколов встреч, фото и видео руководителя для аватара.

## Как проверяем
- Доля писем, разобранных правильно, по полю `expected_action`.
- Ни одно письмо категорий «деньги», «кадры», «обязательства клиентам», «руководство» не обработано без подтверждения.
- Сколько встреч агент может закрыть сам и сколько часов в неделю освобождается.
- Подключение второго профиля: скопируйте `leader_profile.md`, поменяйте цели и правила — агент должен работать без изменения кода.
