# TASK_17: Свежая память помощника

**Кто решил:** Пит, 27.11: «Выполни проверку бота. Актуальность и своевременность актуальности информации в мозгах. По сути бот — это и есть тот самый помощник» → по итогам проверки: «Да. Делай всё».

## Что нашла проверка (стенд, 27.11)

1. Решения руководителя не попадали в память: отказал в отпуске, а «что по отпуску» отвечало «согласовать отпуск»; аватар спросил бы про закрытое.
2. Одна тема жила в нескольких («Облако Плюс» и «Договор с Облако Плюс»), ответ на «что по …» неполный, с повторами.
3. Два календаря: письма — учебный день (DEMO_DATE), факты со встреч — настоящий; встречи «старше» писем на две недели.
4. Мусор проверок на стенде: тестовые протоколы №1, 2, 4–10, тестовые встречи, «решение» из служебной фразы аватара, пересылка уведомления о пароле.
5. Автопилот готовил аватара к встречам без ссылки на Телемост — LiveAvatar падал. Сводка «сделал без вас» — вся история, а не сегодня.

## Поведение

1. Решение руководителя (да / нет) — факт памяти «Иван Петров: отказ — <тема письма>» с его словами из ответа, к темам писем, о которых шла речь. Из журнала (`letter_decided`, `mail_sent` «решение»), один раз; «Позже» — не решение. Перед «что по …», разбором почты, подготовкой аватара и страницей памяти.
2. Темы склеиваются при чтении: основа короткого названия входит в длинное; одно общее слово не склеивает, имя собственное («ТехноСтрой») — да. Название темы — самое короткое. «Что по …» отвечает по всей склеенной теме.
3. `Assistant.now()` — время на рабочем дне помощника; протоколы робота и студии датируются им.
4. Автопилот при роботе: нет ссылки — аватар не идёт, руководителю одно сообщение.
5. `digest_from_journal(…, since=)` — утренний блок «Сделал без вас» за сегодня.
6. Чистка стенда — разовым скриптом с бэкапом, не кодом продукта.
