# ИИ-помощник руководителя

Хакатон «ИИкузница», трек «Цифровой аватар». Заказчик — руководитель направления SMB и Digital. Помощник забирает у руководителя рутину: почту, решения, встречи, протоколы и сроки. Цель — освободить 8–12 часов в неделю.

**Стенд:** https://194-87-110-81.sslip.io/ (запасной адрес: http://194.87.110.81:8080/). Проверка работы: `/health`.

## Что делает помощник

| Где | Что |
|---|---|
| **Почта** | Разбирает каждое письмо: модель определяет категорию, а действие выбирает код по правилам профиля руководителя. Действия: передать исполнителю, ответить самому, положить в сводку, пропустить или уточнить у отправителя, что ему нужно. Деньги, кадры, обязательства клиентам и письма руководству — только с подтверждения руководителя. Ящик проверяется каждые 20 секунд. Кабинет устроен как Outlook: папки, черновики, вложения, ответ уже написан. |
| **Решения** | Одинаковые письма склеиваются в один вопрос. В карточке вопроса есть запрос в одну строку, что мешает, совет и два черновика ответа: на согласие и на отказ. Каждый факт берётся из задач, встреч или памяти и показывается дословно. Карточка есть в кабинете и в Telegram. |
| **Встречи** | Аватар (HeyGen LiveAvatar) сам заходит в Телемост, представляется ИИ-помощником, задаёт вопросы по прошлому протоколу и даёт слово по очереди. После встречи протокол с цитатами из расшифровки уходит на утверждение в Telegram. После утверждения протокол рассылается участникам, задачи ставятся с порядком «после N». |
| **Задачи** | Помощник сам выясняет у исполнителей, почему задача просрочена. Если исполнитель назвал новую дату и она не расходится с планами, помощник переносит срок сам. Ответы попадают в память и в вопросы к следующей встрече. |
| **Telegram** | Утром приходят блоки: решения по одному, график дня, затем «что сделал без вас». Голосом можно ответить на карточку, спросить «что по …» или поручить задачу (Whisper работает на нашем сервере). |
| **Профиль** | Цели, правила, стиль писем, штат, метрики и журнал действий. Новый руководитель — это новая папка `profiles/<id>/` с файлом `profile.md`, код не меняется. |

## Устройство

- `pomoshnik/` — продукт:
  - `triage.py` — правила разбора почты;
  - `decisions.py` — карточки решений;
  - `protocol.py` — протоколы;
  - `memory.py` — память фактов;
  - `assistant.py` — сборка частей;
  - `server.py` — стенд на FastAPI;
  - `static/cabinet/` — кабинет на обычном JS;
  - `robot/` — робот Телемоста;
  - `channels/` — почта (Яндекс IMAP/SMTP, учебный CSV, заглушка Outlook) и Telegram.
- `yadro/` — ядро, наработка до спринта: часы, сроки из русского текста, сверка цитаты с источником, журнал, база.
- `profiles/ivan_petrov/` — профиль руководителя из ТЗ.
- `data/task/` — данные заказчика: 80 писем, календарь, оргструктура, задачи.
- `tests/` — тесты на pytest. Модель в тестах подменена заглушкой.

Главный принцип: модель только читает текст и пишет черновики, а решение принимает код. Цифры, сроки и права на отправку проверяются в коде, факты сверяются с источником. Каждое действие и каждое решение руководителя пишется в журнал.

## Запуск

```bash
python -m venv .venv && .venv/Scripts/pip install -r requirements.txt   # Linux: .venv/bin/pip
cp .env.example .env        # ключ модели (LLM_API_KEY или DEEPSEEK_API_KEY), по желанию Telegram, Яндекс, LiveAvatar
.venv/Scripts/python -m uvicorn pomoshnik.server:app --port 8800
```

Без ключей Telegram и Яндекса стенд работает на учебной почте заказчика. Модель подключается через любой OpenAI-совместимый адрес (`LLM_BASE_URL`, `LLM_MODEL`), поэтому её можно заменить на российскую или локальную. На сервере стенд работает как служба systemd, файл службы — `deploy/ii-pomoshnik.service`.

## Проверка

```bash
.venv/Scripts/python -m pytest -q                         # весь набор, без настоящей модели
.venv/Scripts/python -m pomoshnik.eval_triage --mode rules  # точность разбора почты по эталону заказчика
```

Разбор по эталону: 80 из 80, нарушений запретов 0, без руководителя 50 % (потолок эталона). Модель-разборщик (DeepSeek Flash) — 76 из 80 на замере 26.11. Протокол встречи готов через 16 секунд, стоит $0,005, все 9 цитат найдены в расшифровке.
