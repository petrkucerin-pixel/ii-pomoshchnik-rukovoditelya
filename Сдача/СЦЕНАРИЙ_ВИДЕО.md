# Сценарий демонстрационного видео (до 3 минут, один дубль)

Правила записи:
- один фрагмент без склеек и эффектов;
- можно ускорять только ожидание ответа модели;
- запись экрана стенда https://194-87-110-81.sslip.io/ и Telegram;
- данные — данные задачи.

**Перед записью:** обновить страницу, открыть Telegram на телефоне или в веб-версии рядом с браузером.

| Время | Что на экране | Что сказать (кратко) |
|---|---|---|
| 0:00–0:15 | «Сегодня»: метрики, «Ждут только вас», риски | «Помощник руководителя SMB. За неделю он разобрал 80 писем, половину без руководителя. Освобождённые часы — вот здесь.» |
| 0:15–0:45 | Карточка решения, например «Отпуск сотрудника сервиса»: запрос, что мешает, совет, два черновика. Нажать «Согласовать» | «Сорок писем свелись к восьми вопросам. Факты дословно из задач и календаря, совет, готовый ответ. Одна кнопка, и ответ ушёл.» |
| 0:45–1:15 | «Переписка» → «Входящие»: красная рамка, «Отсортированные / Другие». Открыть письмо с меткой «Передал Ольге Смирновой», затем «Отправленные» | «Что не требует руководителя, помощник сделал сам: передал по оргструктуре, ответил, отправил в сводку. Деньги, кадры, обязательства — только руководителю.» |
| 1:15–1:45 | «Совещания» → встреча → протокол: цитаты, «По прошлому протоколу: было → стало», «Порядок: шаг 1 → шаг 2» | «Аватар провёл встречу в Телемосте и задал вопросы по прошлому протоколу. Протокол готов через секунды, у каждого пункта есть цитата.» |
| 1:45–2:15 | Telegram: протокол на утверждение → «Утвердить» → «разослан участникам» | «Руководитель утверждает протокол в Telegram, рассылка и задачи уходят сами.» |
| 2:15–2:40 | Задача «Подготовить КП» → «Почему просрочена», «Помощник спросил исполнителя, ждём ответ» | «Просрочки помощник выясняет сам. Если исполнитель назвал дату и она не расходится с планами, срок переносится без руководителя.» |
| 2:40–3:00 | «Профиль» → «Правила», «Метрики» | «Профиль — это настройки. Второй руководитель подключается без кода.» |

**Запасной вариант:** если аватар или Telegram подвисли, показать готовый протокол в кабинете и прокомментировать голосом. Монтаж не нужен.
