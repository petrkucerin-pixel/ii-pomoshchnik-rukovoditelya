# TASK_14: Письма без шаблонов — помощник пишет в стиле руководителя и учится на правках

**Кто решил:** Пит, 27.11: «Шаблоны конечно хорошо, но вряд ли руководитель захочет их составлять. По ТЗ мы освобождаем руководителя от рутинной переписки» → «делай полностью».

## Поведение

1. Руководитель шаблоны не составляет. Вкладки «Шаблоны» в «Переписке» нет.
2. Помощник сам составляет себе тексты писем (подтверждение, передача, приглашение и др.) в стиле руководителя — один вызов модели, когда меняются правила стиля.
3. Код проверяет каждый составленный текст: только известные переменные, обязательные переменные на месте (ссылка, срок, задача, подпись…), **ни одной своей цифры** — цифры, даты, имена и ссылки подставляет код. Не прошёл проверку — для этого письма остаётся прежний текст, причина видна в профиле.
4. Правила стиля помощник берёт:
   - из правок руководителя в карточке решения (журнал `decision_draft_edit`, код соседней сессии не меняется): модель сравнивает черновик и правку и формулирует правило, если правка про стиль; правка только про факты правилом не становится;
   - из слов руководителя: «Профиль → Как я пишу → Научить помощника».
5. «Профиль → Как я пишу»: стиль из профиля, правила (откуда взялось, кнопка «Забыть»), как сейчас звучат письма (пример с учебными данными), поле «Научить помощника».
6. Всё живёт в журнале продукта: `style_rule_added`, `style_rule_removed`, `style_learned`, `style_letters`. Переживает перезапуск.

## Стык

- `pomoshnik/writer.py`: `StyleBook(llm, journal, templates, style)` — `rules()`, `render(key, **values)`, `teach(message)`, `forget(rule_id)`, `learn_pending()`, `rules_text()` (для черновиков в `decisions.py` — подключает соседняя сессия), `overview()`.
- `Assistant.send()` рендерит через `StyleBook.render()`.
- API: `GET /api/style`, `POST /api/style/teach {message}`, `DELETE /api/style/rules/{id}`.
