# TASK_15: Утро в Telegram — блоками, приятно читать и действовать

**Кто решил:** Пит, 27.11: «Целая портянка. Давай будет присылаться блоками в определённое время. К примеру „Ждут только вас“ — по каждому пункту отказать/согласовать. Через какое-то время следующий блок. Допустим, разобрали решения — приходит график, или через полчаса после первого сообщения. В ТГ все сообщения должны приходить приятными для чтения и для действия».

## Поведение

1. **Блок 1, в время плана из профиля (08:30), будни.** Приветствие: день недели и дата, сколько встреч и когда первая, сколько вопросов ждут решения, что важно (риски, не больше трёх). Сразу за ним — первая карточка решения с кнопками; остальные — по одной после ответа (карточка — код очереди решений, `_next_decision`).
2. **Блок 2 — график и сроки.** Приходит, когда очередь решений опустела, или через 30 минут после блока 1 — что раньше. Встречи по времени (отмечено, какие ведёт ИИ-аватар), просрочено, сроки на 2 дня словами «сегодня / завтра».
3. **Блок 3 — «Сделал без вас».** Через 30 минут после блока 2. Пусто — не приходит.
4. Каждый блок — один раз в день; что отправлено, хранится в журнале (`tg_block`), переживает перезапуск. День отправки — настоящий день, содержимое — рабочий день помощника (`DEMO_DATE`).
5. Команда «/plan» («план») — график и сроки сразу и кнопка «Решения по одному», если есть вопросы.
6. Окон «под стратегию» в Telegram нет (решение Пита 27.11 убрать окна фокуса).

## Стык

`Assistant.morning_tick()` — вызывает цикл бота на каждом опросе. Рендер блоков — `plan.render_morning`, `plan.render_schedule`, `plan.render_digest`.
