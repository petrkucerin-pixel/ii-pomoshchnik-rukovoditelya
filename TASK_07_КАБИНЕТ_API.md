## Ожидаемое поведение

### Помощник живёт без Telegram и переживает перезапуск
- Стенд создаёт помощника сразу. Пока руководитель не нажал `/start`, сообщения в Telegram не уходят, но кабинет работает.
- Решения «ждут только вас» восстанавливаются из журнала: письмо с действием «спросить руководителя» без записи о решении.
- Каждое исходящее письмо помощника пишется в журнал (`mail_sent`: кому, тема, текст, шаблон, ответ на).

### Группы переписки (код, без модели)
| Группа | Правило |
|---|---|
| `spam` | категория «спам» |
| `newsletter` | категории «рассылка», «приглашение» |
| `team` — Отделы: участники совещаний | человек из оргструктуры, который бывает на **операционных** встречах руководителя |
| `internal` — Отделы: другие | остальные люди из оргструктуры (руководство, финансы, HR, ИТ) |
| `counterparty` — Контрагенты | всё остальное; собеседник — название в «…» из имени отправителя, иначе домен |

Для исходящих группа считается по получателю.

### Шаблоны писем
- Шаблоны: передача исполнителю, автоответ, вопрос ревизора, рассылка протокола, «согласовано», «отказ». Переменные вида `{имя}`.
- Хранятся в папке профиля (`templates.json`), по умолчанию — встроенные тексты. У второго руководителя свои.
- Сохранение с неизвестной переменной → 422. Каждое сохранение — запись `template_edit` в журнал (правка руководителя).
- «Обсудить с помощником»: модель получает шаблон, переменные и просьбу, возвращает ответ и новый вариант. Не сохраняет. Неизвестные переменные в предложении код отмечает в `problems`.
- Помощник отправляет письма по шаблонам.

### Спам
- Категория «спам» в разборе. Код игнорирует спам при любых правилах профиля.
- Учебные спам-письма — `data/demo/spam.csv` (данные заказчика не меняем). Стенд читает их вместе с `inbox.csv`.

1. Письмо клиента «Ромашка-Ритейл» → Контрагенты, собеседник «Ромашка-Ритейл».
2. Статус Сергея Морозова → Отделы: участники совещаний. Письмо Виктора Орлова → Отделы: другие.

4. Решение из кабинета → письмо отправителю, решение уходит из «ждут только вас», после перезапуска не возвращается.
5. Правка шаблона передачи → следующее делегирование уходит с новым текстом. `{zzz}` → 422.
6. Обсуждение шаблона не меняет сохранённый шаблон.
7. Спам-письмо → группа «Спам», действие «игнорировать», даже если модель уверена в другом правиле.
8. Встречи недели 07.12 — только из этой недели, по времени; карточка встречи с задачами участников; неизвестная встреча → 404.
9. Расшифровка → черновик протокола → в списке протоколов и у встречи с тем же названием в тот же день.
